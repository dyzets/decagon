Tips:
- On Windows, capture a window with **Win + Shift + S** (Snipping Tool) or **Alt + PrtSc**.
- Aim for ~1200–1600 px wide; PNG keeps text crisp.
- Keep the aspect ratios similar so the 2-column gallery looks tidy.

You can add or rename images freely — just update the `<img src="...">` paths in the
root `README.md` to match.
